# Public transcript archive

## Channel context

Use the user's channel profile and actual source asset. For Ship Sh!t Show, read [the bundled profile](references/channel-profile.md); viewers using another channel should provide their audience, voice, formats, links and visual references. A profile is context, not permission to publish, upload footage, buy generation or contact a partner.

Inventory by channel ID and YouTube ID, union existing history with current uploads, and deduplicate before writing. A public tab is a lower bound: absence does not prove deletion/private status. Keep existing episode links working. Reconcile both main and Clips channels.

Prefer existing captions/authorized local transcripts; preserve the original raw source plus readable text and source metadata. For local media, use an available local transcription engine when authorized; never send footage to a cloud provider by implication. Stop rate-limited endpoints, record the gap and continue with independent available sources. Do not publish another creator's transcript as channel content.

Give livestream, edited video and each Short their own transcript/timestamp clock. Record source livestream ID, recording/publish dates, channel ID, ASR/caption method, language, corrections and source hashes. Attach cut maps where they exist. Do not guess derivative mappings from a nearby date alone.

Maintain a coverage ledger: archived, transcript located awaiting import, or transcript missing with reason. A placeholder summary is not a transcript. Publish public text/provenance and links; keep multi-gigabyte media/native projects in the editing library. Flag ASR model names, numbers and speaker identities for review instead of silently inventing certainty.

Use the repository's existing frontmatter/paths, with `youtube_tags` for keywords. Validate unique identity, nonempty sources, readable captions, local links and honest statuses. Publication follows the user's authorized repository workflow.
