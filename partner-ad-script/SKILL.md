# Partner host-read script

## Channel context

Use the user's channel profile and actual source asset. For Ship Sh!t Show, read [the bundled profile](references/channel-profile.md); viewers using another channel should provide their audience, voice, formats, links and visual references. A profile is context, not permission to publish, upload footage, buy generation or contact a partner.

Use the partner brief: product/offer, intended audience, relationship, approved facts, evidence, actual host experience, CTA/link, requested length and placement. Ask for missing terms rather than invent an offer, personal endorsement or guaranteed outcome. Distinguish sponsored reads from independent comparisons.

Write a natural host read: clear sponsorship disclosure, a specific viewer problem, supported product benefit/example, honest limits where material, one CTA and a return to the episode. Offer short and standard variants when useful; estimate read length explicitly. Keep host wording conversational and avoid making the partner the apparent author of editorial conclusions.

Return script, optional on-screen text, exact link/offer, factual claim checklist with evidence, and a handoff cue. Indicate which claims need partner/user confirmation. Use a recorded ad/video only if it fits current platform rules and the authorized brief; do not insert a supplied commercial automatically.

Before publication, recheck [YouTube branded-content policy](https://support.google.com/youtube/answer/17596007?hl=en) and applicable market requirements. Include a clear disclosure in the read and Studio's paid-promotion declaration where required; do not claim the checkbox resolves every legal obligation. No partner outreach, contractual acceptance or publication is implied by drafting.
